tlg-axy (branch tlg-axy, 2026-10-21): shadps4/video_core, shadps4/shader_recompiler, shadps4/common,
shadps4/core/libraries/gnmdriver and shadps4/core/libraries/videoout are axylpup's inFAMOUS Second Son build
of shadPS4 (github.com/axylpup/shadPS4, branch second-son, 2212a345 = release v1.0.2, GPL-2.0-or-later;
shadPS4 0.17, upstream main of 2026-08-08, plus ~750 commits). Its release switches (shadps4-flags.txt)
are the game profile's defaults (scripts/game_profiles.py, AXY_RELEASE_FLAGS); its game code patches are
shim/tlg_game_patches.cpp. Port changes on top are marked "tlg-axy:" (and "port:" as before):
common/path_util.{h,cpp} and common/ntapi.h are the port's versions (upstream b4e7ae7 + port changes),
the presenter blits the frame and draws the port's menu instead of shadPS4's ImGui layers, screenshots
are off (no libpng), and the Windows-only diagnostics are stubbed on Linux builds. Also vendored:
third_party/streamline-sdk (NVIDIA Streamline headers, MIT) and third_party/stb (stb_image, public domain).
The previous core (upstream b4e7ae7 with the port's own renderer work, FSR 3/4, TAA, ...) is in the
history of branch tlg.

Vendored from https://github.com/shadps4-emu/shadPS4 commit b4e7ae776071ceb1dd35004577a8719481e1d258 (GPL-2.0-or-later).
